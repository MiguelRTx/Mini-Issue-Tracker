# 🚀 Mini Issue Tracker

Aplicación web para la gestión de proyectos e incidencias (issues/tickets).  
Este proyecto permite organizar tareas, gestionar usuarios y dar seguimiento al progreso de los proyectos.

---

## 📦 Instalación

Sigue estos pasos para configurar el proyecto en tu entorno local:
  bash
  npm install dataenv
  npm install cors 

▶️ Ejecución

Una vez instaladas las dependencias, inicia el servidor con:

npm start
🌐 Acceso

Después de iniciar el proyecto, abre tu navegador y accede a:

http://localhost:3000
